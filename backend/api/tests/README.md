# Тесты для API приложения

В этой директории находятся тесты для API приложения магазина продуктов.

## Структура

- `test_api.py` - Тесты для основных операций с корзиной:
  - GET запрос для получения содержимого корзины авторизованного пользователя
  - POST запрос для добавления товара в корзину авторизованного пользователя

- `test_views.py` - Тесты для публичных API:
  - GET запрос для получения списка категорий
  - GET запрос для получения списка продуктов

- `test_cart_post.py` - Дополнительные тесты для операций с корзиной:
  - GET запрос для получения сводки корзины
  - PUT запрос для изменения количества товара в корзине

## Особенности реализации

- Все тесты используют временную директорию для хранения файлов изображений
- Для аутентифицированных запросов используется токен аутентификации
- Тесты создают необходимые тестовые данные (категории, подкатегории, продукты)
- После выполнения тестов происходит очистка временных файлов
