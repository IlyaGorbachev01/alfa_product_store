# API магазина продуктов

## Описание

Это Django-приложение представляет собой API для интернет-магазина продуктов, реализованное с использованием Django Rest Framework. Приложение позволяет управлять товарами, категориями, подкатегориями и корзиной покупок.

## Функциональность

### Общие возможности:
- Просмотр всех категорий с подкатегориями (публичный доступ)
- Просмотр всех продуктов с фильтрацией по категориям (публичный доступ)
- Пагинация для всех списковых представлений

### Управление товарами:
- Создание, редактирование и удаление категорий и подкатегорий в админке
- Создание, редактирование и удаление продуктов в админке
- Каждая категория/подкатегория имеет: наименование, slug-имя, изображение
- Каждый продукт имеет: наименование, slug-имя, подкатегорию, цену, изображения в 3-х размерах

### Корзина покупок:
- Добавление товаров в корзину (только для авторизованных пользователей)
- Изменение количества товаров в корзине
- Удаление товаров из корзины
- Просмотр состава корзины с подсчетом количества товаров и общей стоимости
- Полная очистка корзины
- Доступ к корзине только для владельца

### Авторизация
- Реализована авторизация по токену
- Разграничение прав доступа к ресурсам

## Технологии

- Python 3.12+
- Django 6.0.2+
- Django REST Framework
- Pillow (для работы с изображениями)
- SQLite (в качестве базы данных)

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-repo/alfa_product_store.git
cd alfa_product_store
```

2. Установите uv (если еще не установлен):
```bash
pip install uv
```

3. Установите зависимости (автоматически создаст виртуальное окружение):
```bash
uv sync --dev
```

4. Активируйте виртуальное окружение:
```bash
source .venv/bin/activate  # для Linux/Mac
# или
.venv\Scripts\activate  # для Windows
```

5. Выполните миграции:
```bash
cd backend
python manage.py migrate
```

6. Создайте суперпользователя:
```bash
python manage.py createsuperuser
```

7. (Опционально) Загрузите данные из фикстур:
```bash
python manage.py loaddata users.json
python manage.py loaddata categories.json
python manage.py loaddata subcategories.json
python manage.py loaddata products.json
```

8. Запустите сервер разработки:
```bash
python manage.py runserver
```

## API Endpoints

### Категории
- `GET /api/categories/` - получить список категорий с подкатегориями (публичный)
- `GET /api/categories/{id}` - получить категорию с подкатегориями (публичный)

### Продукты
- `GET /api/products/` - получить список продуктов (публичный)
- `GET /api/products/{id}` - получить продукт (публичный)

### Корзина
- `GET /api/cart/` - просмотр корзины (только владелец)
- `POST /api/cart/` - добавить товар в корзину (только владелец)
- `PUT /api/cart/{id}/` - изменить товар в корзине (только владелец)
- `PATCH /api/cart/{id}/` - частично изменить товар в корзине (только владелец)
- `DELETE /api/cart/{id}/` - удалить товар из корзины (только владелец)
- `GET /api/cart/summary/` - получить итоговую информацию о корзине (только владелец)
- `POST /api/cart/clear/` - очистить корзину (только владелец)

### Авторизация
- `POST /api/auth/token/` - получить токен

## Админ-панель

Доступна по адресу `/admin/`:
- Управление категориями, подкатегориями и продуктами
- Автогенерация slug из наименования
- Inline-редактирование подкатегорий в категории
- Inline-редактирование продуктов в подкатегории
- Фильтры и поиск

## Настройки

Все настройки проекта находятся в файле `backend/config/settings.py`:
- Пагинация по умолчанию (10 элементов на странице)
- Поддержка русского языка
- Настройки базы данных
- Настройки статических и медиа файлов

## Безопасность

- Права доступа к API:
  - Просмотр категорий и продуктов: любой пользователь
  - Операции с корзиной: только авторизованный пользователь
  - Доступ к своей корзине: только владелец

## Тестирование

Для запуска всех тестов:
```bash
python manage.py test
```

Для запуска конкретного теста:
```bash
python manage.py test api.tests.test_api
```

Для запуска тестов с подробным выводом:
```bash
python manage.py test --verbosity=2
```


## Дополнительная информация

- Все изображения сохраняются в папке `media/`
- Статические файлы собираются в папку `staticfiles/`
- Используется кэширование для списка категорий
- Все модели имеют поля created_at и updated_at
- Для полей наименования и slug используются ограничения на длину
